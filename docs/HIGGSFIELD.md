# Open-source Higgsfield: coverage map

Adrift was built for Comfy's *Open Source Higgsfield* challenge: take the tools on Higgsfield's menus and rebuild them as ComfyUI workflows on open-weight models that you run yourself. This page maps each Higgsfield tool to the Adrift action that covers it. Higgsfield names are used only to identify the feature being matched; Adrift has no affiliation with Higgsfield.

Several Higgsfield headline features already run on open weights: InfiniteTalk (Lipsync Studio, Talking Avatar), Wan Animate (Motion Control, Recast), VibeVoice (Speak, Audio), plus Z-Image, Qwen Image Edit and Wan 2.2 in the image and video menus. Adrift runs the same open models locally, with no credits and no upload.

Statuses: **HAVE** = a shipped Tools-page action or app. **PARTIAL** = part of it ships and the gap is stated. **MISSING** = not built yet; the proposed open-weight path is listed. **nc** = the model weights are non-commercial. Model licences are in [MODELS.md](../MODELS.md), downloads in [models/download-list.md](../models/download-list.md). **Runs on reference backend** = the tool's workflow pack was checked against the author's ComfyUI install: yes / partial / no / app (an app built on checked tools) / untested (the pack has not been loaded on the reference install yet). Qualifiers and parts not yet run on a GPU are in the numbered notes at the end.

## Core tools

83 tools: **HAVE 75 (63 run on the reference backend, 12 untested) / PARTIAL 8 / MISSING 0**. 2 tools whose pack does not run on the reference backend yet are listed as PARTIAL. Not counted: agents, chat assistants, app/game builders, plugins and team features (Adrift has its own HTTP Tools API, see [tools-api.md](tools-api.md)).
