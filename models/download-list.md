# Model download list

For each file's license, gated status and which tools load it, see
[../docs/models.md](../docs/models.md).

Files for the image, edit, video, upscale, 3D, audio and motion-effect tools.
Each URL is pinned to a Hugging Face revision. Save each file to
`ComfyUI/models/<Destination>`. Licenses are in [../MODELS.md](../MODELS.md).
Gated repos require you to accept their terms on Hugging Face first.

There are two sets:

- **minimal**: what the default tools need
- **full**: adds the pack and edit-tool models, motion-effect LoRAs, camera
  control, TTS and alternative quantizations

To try Adrift first, `node scripts/fetch-models.mjs --set starter` fetches
four of these files (about 11 GB): `checkpoints/sd_xl_base_1.0.safetensors`,
`background_removal/birefnet.safetensors`,
`checkpoints/stable_audio_3_small_sfx.safetensors` and
`text_encoders/t5gemma_b_b_ul2.safetensors`.

The Hugging Face file name can differ from the Destination name; save it under
the Destination name, since that is what the graphs load. Some files go to
two destinations (listed as "also"); copy or link it to both.

Download example:

```bash
curl -L --create-dirs -o "ComfyUI/models/<Destination>" "<URL>"
```
